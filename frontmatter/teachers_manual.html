Teacher's Manual

Economics Honors (Florida 2102320) · Teacher-facing only, hidden from students · companion to the Standards Alignment Matrix
What this manual is for. A quick-orientation guide for any teacher picking up this course — what each lesson teaches, which standard(s) it satisfies, what's confirmed-complete versus deferred, and a comprehensive standard-by-standard index so you can find every lesson and assessment that touches a given benchmark. This is a rebuild/rehost of an existing Canvas sandbox course into Optima's current delivery model; content decisions and their rationale are tracked in this build's plan.md decision log — this manual summarizes, it does not replace that log.
Read this before you touch the gradebook.
  • All 24 lesson Assignments are full Tier-3-shaped items (written response, individually rubric-graded) — a deliberate, confirmed override of optima-canvas-assignments' usual Tier-3 ratio cap, matching the source course exactly. This is expected, not a defect. See plan.md decision-log item 7.
  • No due/lock/unlock dates are set anywhere. The source's dates were stale placeholders from an unrelated term and were not carried over. Set real dates before running this course live.
  • Module 5's five Reading Quizzes and the Module 5 Test are empty, unpublished shells — the source itself never authored questions for them. This mirrors the source; it is not a build gap. If you want Module 5 to have working quizzes, new questions need to be authored from scratch.
  • Virtue threads were proposed per module in CLAUDE.md but were never adopted — this build made a deliberate call not to spend time on them. Treat the proposals there as inactive, not pending.
  • The 24 VR Lesson Resources activities are not built. The source's VR pages were empty stubs; authoring new platform-agnostic VR activities was deferred, not declined. See plan.md Finding A.
  • Grading weights are already configured: Module Tests 40%, Reading Quizzes 25%, Writing Assignments 25%, Module Projects 10%.
